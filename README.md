# PingApp — هشدار صوتی اتصال به IP

یک برنامه ساده ویندوزی که یک آدرس IP (یا نام هاست) را به‌صورت مداوم پینگ می‌کند و **لحظه‌ای که ارتباط برقرار شد، هشدار صوتی پخش می‌کند**.

## امکانات

- پینگ دوره‌ای به IP یا هاست دلخواه (پیش‌فرض: `8.8.8.8`)
- تنظیم فاصله بررسی از ۱ ثانیه تا ۱ ساعت
- پخش سه بوق بالارونده هنگام برقراری ارتباط
- گزینه اختیاری: هشدار صوتی هنگام قطع ارتباط
- نمایش وضعیت لحظه‌ای (متصل/قطع) همراه با زمان پاسخ (ms)
- ثبت رویدادها با زمان دقیق در لیست گزارش
- مینیمایز شدن به کنار ساعت (System Tray) با منوی راست‌کلیک فارسی
- نوتیفیکیشن بالونی هنگام برقراری یا قطع ارتباط، حتی وقتی پنجره مخفی است

## پیش‌نیاز ساخت

- [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) یا جدیدتر
- ویندوز ۱۰ یا جدیدتر

## ساخت و اجرا

```powershell
dotnet run
```

## ساخت فایل اجرایی مستقل (بدون نیاز به نصب .NET روی سیستم مقصد)

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

فایل `PingApp.exe` در مسیر زیر ساخته می‌شود:

```
bin\Release\net8.0-windows\win-x64\publish\
```

## نحوه استفاده

1. آدرس IP یا نام هاست موردنظر را وارد کنید.
2. فاصله بررسی (ثانیه) را تنظیم کنید.
3. دکمه **شروع** را بزنید.
4. به محض اینکه دستگاه مقصد به پینگ پاسخ دهد، صدای هشدار پخش می‌شود و وضعیت سبز می‌شود.
